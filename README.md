# Full Court Grind

Vite/React export of the Full Court Grind game.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Push this folder to GitHub.
2. Import the repo in Vercel.
3. Use:
   - Framework Preset: Vite
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Deploy.

The game code is in `src/App.jsx`.
