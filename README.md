# Full Court Grind

A Vite + React build of Full Court Grind, ready for GitHub and Vercel.

## Local setup

```bash
npm install
npm run dev
```

## Production test

```bash
npm run build
npm run preview
```

## Vercel settings

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`
